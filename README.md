# workyr: учёт времени для 3D-моделера

Маленькая программа для Windows. Живёт в трее (иконка возле часов), сама понимает,
когда идёт работа, и считает время по проектам. Для отчётов и счетов заказчикам.

## Как запустить

**Вариант 1: собрать один exe-файл (удобнее всего для подруги)**

1. На любом компьютере с Windows установите Python 3.10+ с python.org
   (при установке отметьте «Add python.exe to PATH»).
2. Дважды щёлкните `build.bat`. Через пару минут появится `dist\workyr.exe`.
3. Скопируйте этот один файл на компьютер подруги и запустите. Python ей не нужен.

**Вариант 2: без сборки**: дважды щёлкните `run.bat` (нужен Python).

## Первый запуск

1. Появится иконка с часами возле часов Windows (может прятаться за стрелкой `^`).
   **Двойной клик** по ней открывает окно, **правый клик** открывает меню.
2. В окне, на вкладке «Проекты», создайте проекты (название, при желании заказчик и ставка).
3. В меню иконки (правый клик) выберите проект, над которым идёт работа. Всё, считается само.
4. Включите «Запускать вместе с Windows» (в меню иконки или во вкладке «Настройки»).

## Как программа решает, что идёт работа

Время идёт на выбранный проект, только если **одновременно**:

- активно окно из списка «Рабочие программы» (по умолчанию Blender, ZBrush, Marmoset Toolbag,
  Substance, Photoshop, Unreal Engine и вкладка браузера со словом Meshy в названии);
- пауза не включена;
- в последние 3 минуты двигалась мышь или перо планшета (или нажималась клавиша).

Если человек отошёл, время за простой **не считается**: программа вычитает «хвост» без движения.
Если ноутбук ушёл в сон, время сна тоже не считается.

Цвет иконки: 🟢 идёт запись · 🟡 рабочее окно, но нет движения · ⚪ сейчас не рабочее окно · 🔴 пауза.

## Если забыла выбрать проект

Время всё равно записывается как «Без проекта», а раз в 20 минут появляется напоминание.
Потом на вкладке «Записи» выделите такие строки и нажмите «Сменить проект».
Там же можно удалить лишнее и добавить время вручную (например, если работала в программе,
которой нет в списке).

## Автоматическое переключение проекта (по желанию)

В карточке проекта можно указать «слова в заголовке окна», например имя файла `chair_v3`.
Когда такое слово есть в заголовке активного окна (в Blender имя файла в заголовке), время
пойдёт в этот проект, даже если в меню выбран другой. Слова должны быть уникальными.

## Отчёты

Вкладка «Отчёт»: период (сегодня, неделя, месяц, всё время, свой период), итоги по проектам,
разбивка по дням, сумма (если указана ставка). Кнопка «Экспорт в CSV» сохраняет таблицу,
которая открывается в Excel. В CSV часы пишутся с запятой (формат для Excel в RU/UA/DE).

## Свои программы

Вкладка «Настройки» → «Рабочие программы». Кнопка «Добавить…» → «Определить программу»:
за 5 секунд переключитесь на нужную программу, и её имя подставится само.
Для сайтов в браузере используйте «Взять заголовок окна» или впишите слово из названия вкладки
(ArtStation, Pinterest, PureRef и т. д.). Для справочных сайтов и PureRef рекомендую добавить
их в список, иначе время «на референсах» считаться не будет.

## Где лежат данные и что программа видит

- Всё хранится локально в `%APPDATA%\workyr\` (кнопка «Открыть папку с данными»):
  `tracker.db` (время), `config.json` (настройки), `workyr.log` (ошибки).
  Для резервной копии достаточно скопировать эту папку.
- Программа читает только: имя активной программы, заголовок окна и время последнего ввода.
  Она **не** записывает нажатия клавиш, не делает снимков экрана и ничего не отправляет в интернет.

## Если что-то не работает

- **Время не идёт у планшета Huion.** Программа следит за курсором и системным вводом, этого
  достаточно для драйвера Huion. Если всё же есть проблемы, увеличьте «простой» в настройках.
- **Антивирус ругается на exe.** Это частая история для программ, собранных PyInstaller:
  добавьте файл в исключения или используйте `run.bat`.
- **Нет иконки.** Посмотрите за стрелкой `^` возле часов; при необходимости перетащите иконку на панель.
- Любые сбои пишутся в `workyr.log`.

## Для разработчика

Тесты логики: `python -m unittest -v test_core`.
Файлы: `core.py` (учёт, БД, отчёты), `winapi.py` (Windows API), `ui.py` (трей и окно), `main.py` (запуск).
